# 📱 Flutter App 02

## 🚀 Overview

This project is my second Flutter application.  
The goal of this project was to go deeper into Flutter fundamentals and improve my understanding of UI structure, theming, navigation, and dynamic rendering.

---

## 🎯 What I Learned

### 🎨 App Theming
- How to apply and configure a global **App Theme**
- Customizing:
  - Colors
  - Text themes
  - Button themes
- Keeping UI consistent across the whole application

---

### 🧩 Better Widget Control
- Improving layout structure and widget composition
- Understanding widget trees more deeply
- Reusing widgets efficiently

---

### 📜 Making UI Scrollable
- Using `ListView.builder` to:
  - Render dynamic lists
  - Build widgets efficiently based on data
- Using `SingleChildScrollView` for:
  - Wrapping content that needs scrolling
  - Handling vertical layouts properly

---

### 🔁 Rendering Widgets from Data
- Displaying widgets dynamically based on a data source
- Looping through data collections
- Generating multiple widgets from structured data

---

### 🔀 Navigation Between Screens
- Navigating between screens using:
  - `Navigator.push`
  - `Navigator.pop`
- Passing data between screens

---

### 📦 Working with Data in Flutter
- Managing local data
- Structuring models
- Connecting UI with data
- Updating UI when data changes
